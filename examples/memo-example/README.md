# quartifyr memo example

A complete, working example of quartifyr's fax-cover-sheet-style memo
cover page (`_extensions/quartifyr/memo_cover.lua`) -- an alternative to
`examples/demo-report/`'s report title page for short, loose-structure
documents. The cover itself (a logo, a left-aligned MEMORANDUM banner,
and a To/From/Date/Re/Cc grid -- not centered like a formal report's
title page) is deliberately minimal, but the body still exercises a real
`reportifyr` fill pass, same as the demo report: one figure (a
milestone timeline generated by `scripts/01_analysis.R`) with a live
caption and a hyperlinked crossref. What's entirely absent, unlike
`examples/demo-report`, is everything else a report's front matter
usually carries -- no ToC, no list of figures/tables, no abbreviations
list, no signature pages.

None of that omission needed any quartifyr code changes: ToC/List of
Figures/List of Tables/abbreviations are `quarto-plus` shortcode divs the
*author* places in the body (see `report.qmd` in `examples/demo-report/`
for what including them looks like), and `signature_page.lua`/
`synopsis.lua` already no-op cleanly when their frontmatter is absent --
this project just never sets `contributors:`/`approvers:`/`synopsis:`,
or those divs. See `_extensions/quartifyr/README.md`'s "Memo cover page"
section for the full `memo:` frontmatter contract.

## Layout

- `report.qmd` -- the shell source. Frontmatter sets `memo:` (the To/
  From/Date/Re/Cc fields), `logo:`/`logo-width:`, `document-status`, and
  the same `header-format:`/`confidentiality:` fields `examples/
  demo-report` uses -- `apply-layout`'s header/footer/page-numbering
  pipeline works for a memo cover too, though *not* identically to a
  report title page: the cover deliberately doesn't get its own
  roman-numeral section (see `_extensions/quartifyr/README.md`'s "Memo
  cover page" section for why -- giving it one would leave a blank page
  between the cover and the body, since a memo has no other front-matter
  content to fill that section with). `number-sections: false` and
  `indent-headers: false` (both unlike the demo report), since a memo
  reads as a loose, short-form document rather than a numbered formal
  report, and `quarto-plus`'s heading indent is meant to line up with
  numbering that's off here.
- `_quarto.yml` -- sets `project: {output-dir: report/shell}`, same
  convention as `examples/demo-report` (see its README for why this is
  load-bearing for `render_report()`).
- `_extensions/quartifyr/` -- a **physical copy** of the repo-root
  `_extensions/quartifyr/`, not a symlink (same reasoning as
  `examples/demo-report/`). Kept in sync via
  `scripts/sync_demo_extension.py`, checked automatically by
  `smoke_test.py`.
- `report/standard_footnotes.yaml` -- deliberately trimmed to a couple of
  generic placeholder abbreviations (`FY`/`Q3`), not reportifyr's full
  default CSR-style glossary that `examples/demo-report` keeps --
  `quartifyr-styling abbrevs` (run unconditionally by `render_report()`)
  hard-requires a non-empty `abbreviations:` block, but this memo's body
  never references any of them via `\gls{}`, so nothing from this file
  actually ends up in the rendered document either way.
- `scripts/01_analysis.R` -- generates `OUTPUTS/figures/budget-timeline.png`
  (with a reportifyr metadata sidecar) via `reportifyr::ggsave_with_metadata()`,
  a simple timeline plot of the milestones listed in `report.qmd`'s
  "Proposed Schedule" section. Already run; the output is committed so
  the example works immediately after a clone, same as `examples/
  demo-report/scripts/01_analysis.R`. Re-run it if you want to regenerate it.
- `render.R` -- runs the full pipeline via the `quartifyr` R package's
  `render_report()` (see the repo-root README), unmodified from
  `examples/demo-report/`'s copy.
- `smoke_test.py` -- automated end-to-end check (see below).

## Quick look: cover only, Quarto alone (no R, no Python)

`../../inst/templates/org-reference.docx` is committed to the repo (see
the repo-root README's "Style YAML and reference-doc" section), so the
memo cover -- logo, MEMORANDUM banner, To/From/Date/Re/Cc grid -- renders
with nothing but Quarto installed:

```bash
cd examples/memo-example
quarto render report.qmd --to docx --reference-doc ../../inst/templates/org-reference.docx \
  -M document-status:DRAFT
```

The `{rpfy}:` figure placeholder stays unresolved in the output --
expected, not a bug: pass 2 (`reportifyr`) never ran. `scripts/
quarto_only_smoke_test.py` (repo root) runs exactly this and asserts on
the result.

## Running it

For the full two-pass pipeline (the real budget-timeline figure filled
in), this repo's toolchain needs to be set up: `Rscript -e
'renv::restore()'` in this directory, the `quartifyr` R package itself
(`Rscript -e 'renv::install("local::../..")'`, from this directory --
installs into this project's own renv library, pulling in
`reportifyr`/`pyro` transitively), and the repo-root Python venv (`uv
venv .venv && uv pip install -e '.[dev]'` from the repo root). See
`examples/demo-report/README.md`'s "Running it" section if
`renv::restore()`/`renv::install()` here unexpectedly tries to reach
GitHub or times out against `a2-ai.r-universe.dev`.

`.report_init.json` is gitignored (it embeds a username/timestamp), so a
fresh clone needs two setup calls before the first render:

```bash
cd examples/memo-example
Rscript -e 'reportifyr::initialize_report_project(project_dir = getwd())'
Rscript -e 'quartifyr::initialize_quartifyr_project(getwd())'

Rscript render.R           # -> report/draft/report-draft.docx
Rscript render.R --final   # also -> report/final/report-final.docx
```

## Smoke test

```bash
source ../../.venv/bin/activate
python3 smoke_test.py
```

First checks `_extensions/quartifyr/` hasn't drifted from the repo-root
copy, then runs `Rscript render.R --final` for real and asserts on the
resulting docx: the logo/MEMORANDUM banner/To/From/Date/Re/Cc fields
rendered (banner and logo left-aligned, not centered), the draft/final
stamp rendered, the budget-timeline figure filled in with a live caption
and hyperlinked crossref, no leftover `{rpfy}:` magic strings, no blank
page between the cover and the body, and -- unlike `examples/demo-report`
-- the *absence* of any title-page/signature-page/synopsis artifacts,
confirming `title_page.lua` and `signature_page.lua` stayed no-ops.
Skips (exit 0) if `Rscript` or `quarto` aren't on `PATH`.
